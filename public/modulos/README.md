# Materiales de Mentoría: Módulos de Validación y Costos

Esta carpeta contiene los módulos educativos interactivos preparados para la sesión de mentoría "Mentoría 2: Evidencia, métricas y decisiones".

## Módulos Incluidos

### 📋 Módulo 1: Validación de Prototipo (`modulo-1-validacion.html`)
Formulario robusto y completo para que los estudiantes registren los resultados de sus pruebas de prototipo con usuarios reales.

**Características:**
- Validación de métricas clave: Intención (Sí/Talvez/No), Claridad (1-5), Satisfacción (1-5)
- Captura de acciones derivadas del feedback
- Sección de estrategia de levantamiento de capital con 5 etapas de fundraising
- Descarga de JSON para análisis detallado
- Exportación de PNG con resumen visual de estadísticas
- Ejemplos específicos guiados (ej: "Comidas Express")
- Soporte para 3 tipos de prototipo: Boceto, Físico, Digital

**Uso:**
Los estudiantes abren el HTML en un navegador y rellenan los datos de sus pruebas de usuario. El formulario valida en tiempo real y proporciona descargas de resultados.

---

### 💰 Módulo 2: Costos y Dinero - Junior (`modulo-2-costos.html`)
Material educativo interactivo diseñado específicamente para startups junior que apenas han validado su idea y no tienen datos financieros completos.

**Características:**
- **Sin campos de datos** - Completamente conceptual y educativo
- 6 secciones principales de aprendizaje:
  1. Educación Pura: Explicación de 3 tipos de costos
  2. Preguntas Interactivas: 5 preguntas clave con respuestas guiadas
  3. Tabla Comparativa: Situaciones mapeadas a acciones
  4. Red Flags: 4 señales de alerta importantes
  5. Checklist de Esta Semana: 5 pasos accionables
  6. Timeline: 5 acciones críticas

- Soporte para múltiples tipos de negocio:
  - 🚀 Apps
  - 💼 Servicios
  - 📦 Productos físicos
  - 🔗 Plataformas
  - 📊 Consultoría

- Sistema interactivo de Q&A con botones que revelan explicaciones
- Ejemplos específicos para cada tipo de negocio
- Focus en ENSEÑAR QUÉ PENSAR, no qué números entrar

**Uso:**
Los estudiantes exploran cada sección a su ritmo, hacen clic en las respuestas para revelar explicaciones y aprenden los conceptos fundamentales de costos y financiamiento para startups.

---

## Información Técnica

**Requisitos:**
- Navegador moderno (Chrome, Firefox, Safari, Edge)
- JavaScript habilitado
- Conexión a internet (para descargas de PNG en Módulo 1)

**Tecnologías usadas:**
- HTML5 + CSS3 + JavaScript vanilla
- html2canvas + jsPDF (para generación de descargas en Módulo 1)
- Chart.js (si aplica)
- Diseño responsive para móvil y escritorio

## Cómo Usar en la Mentoría

1. **Preparación:** Comparte los enlaces a estos módulos con los estudiantes antes de la sesión
2. **Módulo 1:** Asigna como ejercicio para que traigan datos reales de sus pruebas de usuario
3. **Módulo 2:** Usa como material educativo durante la sesión para explicar conceptos de costos
4. **Post-mentoría:** Los estudiantes pueden revisitar estos módulos para reforzar conceptos

---

## Notas Importantes

- **Nivel de dificultad:** Junior - Diseñado para fundadores sin experiencia en finanzas o validación formal
- **Accesibilidad:** Ambos módulos funcionan sin necesidad de instalar software adicional
- **Flexibilidad:** Los módulos no requieren datos exactos o completos - el énfasis es en la educación y el pensamiento crítico
